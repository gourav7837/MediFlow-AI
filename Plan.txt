Product Requirements Document (PRD): MediFlow AI (Hackathon 4-Hour Edition)1. Executive Summary & ObjectiveProduct Name: MediFlow AIObjective: Build a streamlined, high-impact clinic management web application in 4 hours that solves real administrative bottlenecks (queues, messy clinical note-taking, patient medication reminders) using a modern tech stack and Google’s Gemma 4 open-weight model for intelligent medical data structuring.Tech Stack:Frontend: React.js, Tailwind CSSBackend: Node.js, Express.jsDatabase & Auth: Firebase Authentication & Cloud FirestoreAI Engine: Google Gemma 4 (running locally via Ollama) utilizing its native function-calling and structured text extraction capabilities.2. User Roles & Scope (4-Hour MVP Focus)To stay strictly within a 4-hour build window, the app focuses on 3 core screens:Receptionist / Admin: Manages the live queue and token numbers.Doctor / Clinician: Inputs raw notes and converts them to structured EMR records using Gemma 4.Patient: Manages personal medication reminders and checks upcoming appointments.3. Detailed Functional RequirementsModule 1: Authentication (Firebase Auth)FR-1.1: Email/Password authentication using Firebase Web SDK.FR-1.2: Single Login/Register screen that routes users based on their selected role or hardcoded mock profile for rapid demoing.Module 2: Receptionist Queue Token DashboardFR-2.1: Displays today's active live queue list fetched from Firestore.FR-2.2: Shows current token state (Token #A34 - Waiting or In Consultation).FR-2.3: Simple state transition button to update token statuses in real-time.Module 3: Doctor EMR & Gemma 4 AI Note ParserFR-3.1: A dedicated consultation input field where doctors type shorthand, messy notes (e.g., "patient has 101 fever, dry cough for 3 days, bp normal, prescribe paracetamol").FR-3.2: AI Summarization Action: Clicking the "✨ Parse with Gemma 4" button sends the text to the Node.js backend.FR-3.3: The backend prompts local Gemma 4 to parse the notes into clean JSON format (chiefComplaints, vitals, diagnosis, treatmentPlan) and returns it to the React UI to auto-populate the prescription layout.Module 4: Patient Portal & Medication RemindersFR-4.1: Clean dashboard showing upcoming clinical appointments.FR-4.2: Interactive toggle switches for active medicine reminders (e.g., Metformin - 8:00 PM) linked directly to Firestore documents.4.
